# Development of a Smart Vehicle Health Intelligence and Predictive Maintenance Recommendation System

## Overview

This project presents an AI-powered predictive maintenance system for Flex Fuel Vehicles (E20–E85). The system uses machine learning techniques to predict vehicle maintenance requirements before component failure occurs, helping improve vehicle reliability, reduce maintenance costs, and minimize unexpected breakdowns.

The project is developed as a B.Tech Final Year Project using a research-grade synthetic dataset based on realistic automotive engineering principles.

---

## Objectives

- Predict vehicle maintenance requirements.
- Compare multiple machine learning algorithms.
- Explain predictions using Explainable AI (SHAP).
- Calculate a Vehicle Health Score.
- Generate intelligent maintenance recommendations.
- Provide a simple user interface for predictions.
